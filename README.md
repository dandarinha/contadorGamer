# 🎮 Contador Gamer

Projeto desenvolvido em React Native com Expo.

---

# Preview do APP

O aplicativo possui:
* contador de pontos;
* botão de aumentar;
* botão de diminuir;
* botão de reset;
* interface estilo gamer;

---

# Tecnologia utilizadas

* React Native 
* Expo
* JavaScript

---

# Como executar o projeto

## 1. clonar o repositório

```
git clone https://github.com/dandarinha/contadorGamer.git
```

## 2. entrar na pasta

```
cd contadorGamer
```

## 3. instalar dependências

```
npm install
```

## 4. rodar o projeto

```
npm start
```
